# Gama Animation Engine (GAE) / Gamatutor

**Gama Animation Engine (GAE)** is an open-source Delphi/Pascal-based animation engine, tutorial editor, and tutorial player originally developed at Universitas Gadjah Mada (UGM). It includes tools for recording, creating step-by-step interactive animations, and labeling Electronic Medical Record (EMR / RME) workflows.

## 🛠️ Development & Building

### Requirements
- **IDE:** Delphi (Embarcadero Delphi 7 / Delphi 2007 or modern Delphi / Lazarus with minor porting)
- **Language:** Object Pascal

### Building
1. Open the project file:
   - For Engine: src/engine/TutorialGenerator.dpr (or main project file)
   - For Player: src/player/PlayerAnimasi.dpr (or main project file)
2. Build/Compile via Delphi IDE (Ctrl + F9 or Project -> Build).
